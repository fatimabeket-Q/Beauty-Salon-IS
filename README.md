# Beauty Salon Information System

## Жоба туралы
Бұл жоба сұлулық салонының жұмысын автоматтандыруға арналған ақпараттық жүйе.

## Жобаның мақсаты
Пайдаланушыларға салон қызметтерін көру, мамандар туралы ақпарат алу, процедураларға жазылу және жазылымдарды басқару мүмкіндігін беру.

## Негізгі кестелер
1. **Clients** — клиенттер туралы ақпарат.
2. **Employees** — салон қызметкерлері туралы ақпарат.
3. **Services** — салонда көрсетілетін қызметтер туралы ақпарат.
4. **Appointments** — клиенттердің қабылдауға жазылу мәліметтері.

## Кестелер арасындағы байланыстар
- Clients → Appointments (1:N)
- Employees → Appointments (1:N)
- Services → Appointments (1:N)
